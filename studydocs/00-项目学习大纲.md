# OpenClaw 项目学习大纲

## 1. 项目概述

- [ ] 项目定位：AI 消息代理 (AI Messaging Agent)
- [ ] 核心功能：连接 AI 模型与多个消息渠道
- [ ] 技术栈：TypeScript, Node.js, Bun

## 2. 核心架构

### 2.1 插件系统 (Plugin System)

- [ ] 插件架构设计思想
- [ ] 插件类型：Channel Plugin / Provider Plugin
- [ ] 插件加载与生命周期
- [ ] 插件清单 (manifest) 规范

### 2.2 消息渠道 (Channels)

- [ ] 核心渠道：`src/telegram`, `src/discord`, `src/slack`, `src/signal`, `src/imessage`, `src/web`
- [ ] 渠道抽象层：`src/channels/`
- [ ] 路由：`src/routing/`

### 2.3 AI 提供商 (Providers)

- [ ] Provider 插件架构
- [ ] 模型调用抽象
- [ ] 主流 provider 支持

### 2.4 网关 (Gateway)

- [ ] Gateway 控制平面
- [ ] 节点有线协议
- [ ] 协议版本管理

## 3. 代码结构

```
src/
├── cli/           # CLI 命令行接口
├── commands/      # 命令实现
├── channels/      # 渠道实现
├── plugins/       # 插件系统
├── gateway/       # 网关
├── infra/         # 基础设施
├── media/         # 媒体处理
├── provider-web.ts
└── plugin-sdk/    # 插件 SDK (公共接口)
```

**关键文件：**

- [ ] `src/plugin-sdk/` - 插件开发 SDK
- [ ] `src/plugins/` - 插件加载器
- [ ] `src/gateway/protocol/` - 协议定义
